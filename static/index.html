Create or pick a topic. A topic decides what to monitor; accounts are flagged only for how they behave (automation, coordination, fake engagement), never for the opinion they express.

Bot likelihood

The score measures how automated an account's behaviour looks: no daily rest, clockwork timing, instant replies, copy-paste text, link spam, volume, account age. Automated is not the same as malicious (announced utility bots score high), and human-run sock puppets usually score low; check the Multi-account tab for those.

Pick a post to see how it gained traction and who it targets.

Scores combine writing style (topic-masked), active hours, typing habits, shared threads/communities, interactions, usernames, account age and cross-links, each calibrated against every other pair in the dataset. A high score is a lead to review, not proof: shared devices, households, coworkers and bots built from one template look alike.

Dataset

The demo is synthetic: invented accounts with a planted sock-puppet ring, a boosted post, scheduled posters and a linked Twitter account.

Collect from Reddit

Uses Reddit's API (OAuth when REDDIT_CLIENT_ID/REDDIT_CLIENT_SECRET are set). Reddit returns at most ~1000 recent items per listing; import an archive for older history.

Import other platforms or archives

Generic JSON (accounts / posts / comments / links for any platform: Twitter/X, Mastodon, YouTube…) or Reddit NDJSON dumps (Pushshift / Arctic Shift). See samples/.

Confirmed identity links

Record links you have verified (e.g. a profile that names its Reddit account). They become sameAs edges and route through the graph.
